# KINU 線上購物 使用說明

## 1. 網站畫面介紹

- **最上方橫幅**：顯示目前的優惠訊息，例如「全館滿 NT$2,500，享免運服務」
- **主選單**：「新品」「女裝」「男裝」「兒童」「為你推薦」
- **搜尋框**：輸入商品名稱，快速找到商品
- **右上角功能列**：收藏、購物車、折價券、訂單、客服、會員登入
- **語言切換**：可切換「繁體中文」「English」「日本語」「한국어」
- **頁尾**：「配送與退貨」「常見問題」「聯絡我們」

## 2. 登入與建立會員

1. 點右上角的「登入」
2. 點「使用 Google 登入」，選擇自己的 Google 帳號
3. 第一次登入時，系統會自動建立會員

- 不需要另外註冊，有 Google 帳號就能使用。
- 不登入也可以瀏覽商品；收藏、購物車、結帳、查詢訂單、客服等功能需要先登入。

## 3. 填寫會員資料

第一次登入後，會自動進入「填寫會員資料」頁：

1. 填寫「姓名」「手機」「性別」「生日」
2. 「地址」可以不填；有填的話，結帳時會自動帶入當作宅配地址
3. 點「完成」

## 4. 找商品

### 依分類瀏覽
1. 把滑鼠移到主選單的「女裝」「男裝」或「兒童」
2. 在展開的選單點選分類，或點「瀏覽全部」
3. 進入商品列表後，可以再點上方的子分類縮小範圍

### 篩選
- 可依「顏色」「尺寸」「價格」篩選商品
- 價格：輸入「最低」「最高」金額後，點「套用價格」
- 點「清除所有篩選」可以全部重設

### 排序
- 「最新上架」
- 「價格：低到高」
- 「價格：高到低」

### 搜尋
在上方搜尋框輸入關鍵字（例如「外套」），就會列出相關商品，搜尋結果也可以排序。

### 新品
點主選單的「新品」，查看最新上架的商品。

## 5. 選購商品

1. 點商品圖片，進入商品頁
2. 點選顏色縮圖，切換想要的顏色
3. 選擇「尺寸」（缺貨的尺寸會反灰，無法選擇）
4. 用「＋」「－」調整「數量」
5. 點「加入購物車」，出現「已加入購物車」即完成

商品頁下方可以查看「商品說明」「退換貨說明」「運費說明」。

## 6. 收藏商品

1. 在商品列表或商品頁點愛心圖示，就會加入收藏
2. 再點一次愛心可以取消收藏
3. 點右上角的「收藏」，可以查看所有收藏的商品

收藏的商品如果下架，會顯示「已下架」。

## 7. 購物車

- 用「＋」「－」調整數量
- 點「移除」刪除商品
- 右側「訂單摘要」會顯示商品小計、運費、折價券折抵與合計
- 商品若顯示「已下架，請移除後再結帳」，需要先移除才能結帳

### 運費
- 單筆訂單滿 **NT$2,500 免運**
- 未滿 NT$2,500，運費 **NT$50**
- 宅配與超商取貨運費相同
- 購物車會提醒「再買 NT$○○ 即可免運」

## 8. 折價券

### 使用折價券
1. 在購物車的「我的折價券」區，選擇一張要使用的折價券
2. 選好後，合計金額會自動扣除折抵
3. 不想使用的話，選「不使用折價券」

- 每筆訂單只能使用一張折價券。
- 未達使用門檻的折價券，會顯示「還差 NT$○○ 可使用」。

### 折價券種類
| 種類 | 範例 |
|---|---|
| 折抵金額 | 「100 元」：直接折 100 元 |
| 打折 | 「9 折」：金額打九折 |

### 查看我的折價券
點右上角的「折價券」，可以看到「可使用」「已使用」「已過期」的折價券。

## 9. 結帳

### 填寫收件資料
1. 在購物車點「前往結帳」
2. 確認「購買商品」是否正確
3. 填寫「收件人」「手機」「Email（訂單通知用）」
   - 收件人是自己的話，勾選「同訂購人」可以自動帶入
4. 有特別需求可以填寫「備註」

### 選擇配送方式
| 配送方式 | 需要填寫 |
|---|---|
| 宅配 | 宅配地址 |
| 超商取貨 | 超商門市名稱 |

### 選擇付款方式
| 付款方式 | 說明 |
|---|---|
| 信用卡 | 下單後前往綠界付款頁完成付款 |
| ATM 轉帳 | 下單後前往綠界付款頁取得轉帳資訊 |
| 貨到付款 | 直接完成下單，收到商品時付款 |

### 送出訂單
1. 確認右側金額
2. 點「確認下單」（信用卡、ATM 會顯示「確認下單並前往綠界付款」）
3. 信用卡、ATM：依綠界付款頁的指示完成付款
4. 完成後會看到「訂單已成立」頁與「訂單編號」

- 前往付款頁後，請不要重複送出同一個購物車，以免訂單重複成立。
- 訂單成立不代表已完成付款，可以到「我的訂單」確認狀態。

## 10. 查詢訂單

1. 點右上角的「訂單」
2. 點上方的狀態標籤，切換查看不同狀態的訂單

| 狀態 | 說明 |
|---|---|
| 未付款 | 訂單已成立，尚未完成付款 |
| 訂單確認中 | 已收到訂單，正在準備出貨 |
| 已出貨 | 商品已寄出 |
| 已送達 | 宅配已送達 |
| 取貨完畢 | 已取貨 |
| 已取消 | 訂單已取消 |

如需取消訂單或有訂單問題，請透過「客服中心」聯絡。

## 11. 客服中心

### 送出客服單
1. 點右上角的「客服」
2. 填寫「聯絡 Email」
3. 選擇「問題類型」
4. 在「問題內容」描述狀況，建議附上訂單編號或商品名稱
5. 點「送出客服單」，畫面會顯示客服單號

**問題類型**：訂單與物流、退換貨、商品諮詢、付款與發票、折價券與活動、會員帳號問題、其他

### 查看回覆
同一頁下方的「我的客服單」會顯示客服回覆，以及「處理中」或「已解決」的狀態。

## 12. 退換貨

- 商品到貨後 **7 天內**可申請退換貨（鑑賞期非試用期）
- 退換商品需保持全新、吊牌完整，並附上原包裝與發票
- 貼身衣物（內衣褲、襪子）及特價出清商品，基於衛生考量恕不接受退換
- **申請方式**：到「客服中心」送出客服單，問題類型選「退換貨」

## 13. 為你推薦

- 點主選單的「為你推薦」查看推薦商品
- **未登入**：顯示目前的熱門商品
- **已登入**：依照瀏覽過的商品，推薦可能喜歡的款式

### 清除瀏覽紀錄
1. 在「為你推薦」頁點「推薦設定」
2. 點「清除瀏覽紀錄」
3. 清除後，推薦會依之後的瀏覽紀錄重新產生
