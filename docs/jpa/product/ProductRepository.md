# ProductRepository

- **檢查 slug 是否存在**：給一個 slug，回傳是否已有商品使用。
- **檢查商品貨號是否被使用**：給一段 slug 結尾文字（例如貨號後綴），回傳是否有商品的 slug 以它結尾。
- **分類商品篩選列表**：查指定多個分類底下、指定狀態的商品，並支援分頁。價格下限、價格上限沒帶就不篩；顏色、尺寸沒選就不篩。同時選顏色和尺寸時，必須是同一個 SKU 同時符合才算。
- **依 slug 查上架商品**：給一個 slug，只查狀態為上架中的商品，查不到時回傳空結果。
- **依名稱搜尋商品**：查指定狀態、名稱包含關鍵字的商品，不分大小寫，並支援分頁。
- **查新品**：查指定狀態且標示為新品的商品，並支援分頁。
- **關鍵字加風格搜尋**：查指定狀態的商品，條件是名稱包含關鍵字（不分大小寫）、屬於直接符合的風格，或屬於相關風格，三者符合其一即可。排序依序為名稱符合、直接風格符合、相關風格符合，並支援分頁。直接風格或相關風格清單可能是空的，空清單時要跳過該條件。
- **會員推薦商品**：依指定會員的瀏覽紀錄，把瀏覽次數加總成各風格分數，找出擁有這些風格、會員尚未瀏覽過的上架商品。排序依序為風格總分高到低、最近瀏覽時間新到舊、熱門商品優先、商品 id 大到小。只回傳商品 id，數量由分頁決定。
- **後台商品列表**：關鍵字比對商品名稱或 slug，不分大小寫；關鍵字為空字串時查全部。狀態沒帶就不篩，並支援分頁。
- **到期商品自動下架**：把狀態為上架中、已設定預定下架時間、且時間已到的商品一次改為下架，同時清空預定下架時間，並回傳實際下架的筆數。更新前要先把未送出的異動寫入資料庫，更新後要清除持久化內容，避免讀到舊資料。
