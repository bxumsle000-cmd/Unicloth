# ProductVariantRepository

- **查多件商品的 SKU**：給多個商品 id，一次查出這些商品的所有 SKU，依 SKU id 由小到大排序。
- **查一件商品的 SKU**：給一個商品 id，查出它的所有 SKU，依 SKU id 由小到大排序。
- **庫存警示**：查指定商品狀態、庫存小於等於門檻的 SKU，並同時載入商品資料，避免逐筆再查商品。排序依序為商品 id 大到小、庫存少到多、SKU id 小到大。
- **鎖定 SKU 供庫存異動**：給多個 SKU id，查出這些 SKU 並同時載入商品資料。查詢時要加上悲觀寫入鎖，讓其他庫存異動等目前交易結束。
- **查可篩選的顏色**：查指定多個分類底下、指定商品狀態的 SKU 出現過哪些顏色，結果不重複，只回傳顏色文字。
- **查可篩選的尺寸**：查指定多個分類底下、指定商品狀態的 SKU 出現過哪些尺寸，結果不重複，只回傳尺寸文字。
- **檢查 SKU 代碼是否存在**：給多個 SKU 代碼，只要其中一個已存在就回傳是。
- **扣庫存**：給 SKU id 和數量，只有庫存足夠時才扣除，並回傳更新筆數；庫存不足或 SKU 不存在時回傳 0。
- **補回庫存**：給 SKU id 和數量，把數量加回庫存，並回傳更新筆數。
