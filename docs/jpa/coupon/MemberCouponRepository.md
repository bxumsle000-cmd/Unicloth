# MemberCouponRepository

- **確認券屬於會員**：給會員券 id 和會員 id，查出屬於該會員的券，查不到時回傳空結果。
- **標記券已使用**：給會員券 id、訂單和使用時間，只有尚未使用的券才寫入使用時間和訂單，並回傳更新筆數；已被用掉時回傳 0。
- **查已領券的會員**：給折價券 id、領取來源和起始時間，查出在這個時間（含）之後，以該來源領過這張券的會員 id。只回傳會員 id。
- **查會員的所有券**：給會員，查出該會員的券，依到期時間由早到晚排序。
- **後台發券紀錄**：查每張發出的券，回傳 CouponRecordResponse，內容包含會員券 id、領取時間、姓名、email、折扣碼、券名稱、來源、到期時間、使用時間、訂單編號和訂單折扣金額，並支援分頁。
  - 排序：領取時間由新到舊，相同時再依會員券 id 由大到小。
  - 資料連接：沒有個人資料的會員和未使用的券也要查到，姓名、訂單資料為 null。會員和會員個人資料之間沒有 JPA 關聯。
  - 篩選：以下條件都是 null 就不篩。
    - 關鍵字比對 email 或姓名，不分大小寫。傳入的關鍵字已轉小寫，且前後已加上百分比符號。
    - 折價券 id 和來源要完全相等。
    - 狀態傳入文字，已使用代表使用時間不為 null；已過期代表未使用且到期時間早於現在；可使用代表未使用且到期時間不早於現在。
    - 領取時間的起始值包含在內，結束值不包含在內。
