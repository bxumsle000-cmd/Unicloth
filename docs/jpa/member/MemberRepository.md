# MemberRepository

- **依 email 查會員**：給 email，查出會員，查不到時回傳空結果。
- **依 Firebase uid 查會員**：給 Firebase uid，查出會員，查不到時回傳空結果。
- **依狀態查會員**：給會員狀態，查出該狀態的所有會員。
- **依多個 id 和狀態查會員**：給多個會員 id 和一個狀態，查出同時符合的會員。
- **發券選擇名單**：查指定狀態的會員，回傳會員 id、姓名和 email 組成的 IssueMemberResponse，依會員 id 排序。會員和會員個人資料之間沒有 JPA 關聯；沒有個人資料的會員也要查到，姓名為 null。
- **依生日月份查會員**：給月份和狀態，查出個人資料中生日在該月份、且狀態符合的會員，依會員 id 排序。沒有個人資料的會員不列入。
