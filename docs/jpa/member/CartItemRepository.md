# CartItemRepository

- **購物車頁面資料**：給會員 id，查出該會員的購物車項目，並同時載入 SKU 和商品，避免逐筆再查。依建立時間由舊到新排序。
- **查會員的同一個 SKU**：給會員和 SKU，查出對應的購物車項目，查不到時回傳空結果。
- **查會員的指定項目**：給購物車項目 id 和會員，查出屬於該會員的項目，查不到時回傳空結果。
- **刪除會員的指定項目**：給購物車項目 id 和會員，只能刪除屬於該會員的項目，並回傳刪除筆數。
- **結帳勾選項目**：給會員 id 和多個購物車項目 id，查出屬於該會員且被勾選的項目，並同時載入 SKU 和商品。依建立時間由舊到新排序；別人的購物車項目不可查到。
