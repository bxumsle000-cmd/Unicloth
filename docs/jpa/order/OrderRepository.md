# OrderRepository

- **依訂單編號查訂單**：給訂單編號，查出訂單，查不到時回傳空結果。
- **檢查訂單編號是否存在**：給訂單編號，回傳是否已被使用。
- **會員訂單列表**：給會員 id，查出該會員的訂單，依建立時間由新到舊排序。
- **後台訂單列表**：關鍵字比對訂單編號、會員 email 或收件人，不分大小寫；關鍵字為空字串時查全部。訂單狀態和配送方式是 null 就不篩。查詢時要同時載入會員，避免每筆訂單再查一次會員，並支援分頁。
- **查逾時未付款訂單**：給訂單狀態、付款方式和時間，查出狀態與付款方式符合、付款時間為 null、且建立時間早於該時間的訂單。
- **依訂單編號鎖定訂單**：給訂單編號，查出訂單並加上悲觀寫入鎖，避免同一張訂單同時建立多筆付款紀錄。查不到時回傳空結果。
- **依訂單 id 鎖定訂單**：給訂單 id，查出訂單並加上悲觀寫入鎖，避免不同付款通知同時更新訂單。查不到時回傳空結果。
